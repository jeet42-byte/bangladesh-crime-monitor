# Charting form: Tier A (Bangladesh), full text

One row per included study in `charting_tierA.xlsx`. Use the listed codes. If a
field doesn't apply, write `na`. If the paper doesn't say, write `nr` (not
reported).

## A. Record
| Field | What to enter |
|---|---|
| record_id | Pre-filled (R0001…) |
| final_decision | include / exclude (full text). If exclude, give the reason: not cybercrime, wrong country, not research, no full text |

## B. Study
| Field | Codes |
|---|---|
| doc_type | journal article / conference paper / thesis / book chapter / report / policy brief / preprint |
| discipline | criminology / law / sociology / psychology-public health / media-communication / computer science / business-finance / other |
| design | quantitative survey / qualitative / mixed methods / legal-doctrinal / review / content analysis (news, social media) / technical (model, tool) / commentary |
| data_source | survey / interviews-FGD / police or court records / news reports / social media data / official statistics / legal texts / secondary literature / technical dataset |
| population | university students / school adolescents / women / children / journalists / general public / police or justice actors / organisations or banks / MFS users / none |
| sample_size | number, or `na` |
| location | national / Dhaka / named district(s) / online only / nr |
| data_years | years the data cover, e.g. 2022–2023 |

## C. Cybercrime
| Field | Codes (choose all that apply, separated by `;`) |
|---|---|
| crime_type | mfs_fraud / online_fraud_scam / phishing / hacking_account_takeover / sextortion_image_abuse / cyberbullying_harassment / online_child_abuse / deepfakes / hate_speech_misinfo / online_gambling / data_breach_privacy / attack_on_organisation / speech_offence_cyber_law / general_cybercrime |
| focus | victimisation / offending / policing-investigation / prosecution-courts-evidence / law-policy / prevention-awareness / harm-impact (health, financial) / speech regulation / detection-technical |
| law_discussed | ICT Act 2006 / DSA 2018 / CSA 2023 / Ordinance 2025 / CSA 2026 / Pornography Control Act 2012 / Penal Code / Evidence Act / none |
| theory | e.g. routine activity theory, lifestyle-routine activities, general strain, social learning, space transition, feminist, securitisation, none |
| gender_lens | yes / no |

## D. Findings
| Field | What to enter |
|---|---|
| key_findings | 1–2 sentences, in your own words |
| prevalence_reported | e.g. "38% cyberbullying victimisation, n=400", or `none` |
| author_gaps | gaps or future research the authors themselves name (short) |
| recommendations | the main policy or practice recommendations (short) |
| quality_note | anything notable: predatory-looking venue, no methods section, AI-generated text, etc. Not a formal appraisal. |

## Gap typology (used after charting)
Population · evidence · methodological · empirical · theoretical · practical.
For each cell of crime_type × focus × design, the evidence map shows which
cells are empty or thin. Those empty or thin cells are the candidate gaps.
